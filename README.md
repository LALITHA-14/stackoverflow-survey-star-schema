# Stack Overflow Survey Star Schema Analytics

## Objective

Build a PostgreSQL star schema from the Stack Overflow Developer Survey 2023, load the survey data with Python/psycopg2, run five analytical window-function queries, export their results to CSV, and save the corresponding EXPLAIN ANALYZE plans.

## Structure

```text
schema/
  schema.sql
  indexes.sql
scripts/
  load_data.py
  run_analysis.py
queries/
  query_1_salary_percentile.sql
  query_2_top_technologies.sql
  query_3_compensation_rank.sql
  query_4_desired_technologies.sql
  query_5_compensation_comparison.sql
output/
explain_analyze/
data/
  survey_results_public.csv
```

The raw CSV is intentionally ignored by Git.

## Database

PostgreSQL 13 is used with:

- Database: `survey_db`
- User: `survey_user`
- Password: `survey_password`
- Container port: `5432`

## Normal Docker workflow

If Windows port 5432 is free:

```cmd
docker compose up -d
.venv\Scripts\activate
python scripts/load_data.py
python scripts/run_analysis.py
```

## Conflict-free Windows workflow

If another Windows process already owns host port 5432, use the local override. This keeps PostgreSQL on its normal container port while the Python scripts run inside the Docker network.

```cmd
docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build postgres
docker compose -f docker-compose.yml -f docker-compose.local.yml run --rm etl python scripts/load_data.py
docker compose -f docker-compose.yml -f docker-compose.local.yml run --rm etl python scripts/run_analysis.py
```

The local workflow does not require Windows PostgreSQL to be stopped.

## Verification

```cmd
docker compose -f docker-compose.yml -f docker-compose.local.yml exec postgres psql -U survey_user -d survey_db -c "\dt"
```

```cmd
docker compose -f docker-compose.yml -f docker-compose.local.yml exec postgres psql -U survey_user -d survey_db -c "SELECT COUNT(*) FROM fact_responses;"
```

Check generated files:

```cmd
dir output
dir explain_analyze
```

The five output CSV files and five EXPLAIN ANALYZE files are generated by `scripts/run_analysis.py`.
